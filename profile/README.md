## 🔹 Our Tiered API Offerings

We create small, demonstrable backend APIs to showcase production-ready capabilities at different levels of complexity.

| Tier | Description | Example Repo |
|------|-------------|--------------|
| **Tier 1** | Minimal, demo-ready CRUD APIs using ASP.NET Core & EF Core In-Memory. Quick to run locally, perfect for client demos and portfolio showcase. | [Contacts API — Minimal CRUD Service](https://github.com/Serrao-Software-Studio/contacts-api-tier1) |
| **Tier 2** | Lightweight MVP backends with SQLite persistence, Swagger/OpenAPI, Dockerfile, and basic validations. Ideal for proof-of-concept or small client projects. | *(Coming Soon)* |
| **Tier 3** | Production-ready foundations with layered architecture (Services → Repository), JWT auth skeletons, unit tests, validation, Docker Compose setups, and optional third-party integrations. | *(Coming Soon)* |

> Each tier builds on the previous, so clients can scale seamlessly from demo to production.

## 🛠️ Tech Stack

- **Backend:** .NET 9 / ASP.NET Core Web API  
- **Persistence:** EF Core (In-Memory, SQLite, SQL Server)  
- **APIs & Docs:** Swagger / OpenAPI  
- **Containers:** Docker / Docker Compose  
- **Extras:** JWT authentication skeleton, unit tests, validation, CI/CD ready
